# AGENTS.md

## Architecture

Monorepo with two independent packages:

- `backend/` — Go 1.26, chi router, SQLite (modernc.org/sqlite, pure Go), JWT auth
- `frontend/` — React 19, Vite 8, TanStack Router (file-based), Tailwind CSS v4, shadcn/ui

Separate domains in production:
- `financensor.stammkneipe.dev` → frontend SPA (nginx)
- `api.financensor.stammkneipe.dev` → backend REST API

Auth: Google OAuth → JWT Bearer token stored in localStorage, sent as `Authorization: Bearer <token>`.

## Dev Commands

```bash
# Backend
cd backend && go run ./cmd/server   # loads .env via godotenv

# Frontend
cd frontend && npm run dev           # Vite dev server on :5173, proxies /api to :8080

# Verify
cd backend && go build ./...
cd frontend && npx tsc -b && npx vite build
```

## Deploy

Target: Hetzner VPS (`ssh hetzner`), Docker Compose with Traefik (auto-HTTPS).

```bash
mise run deploy        # rsync + env + build on server (no release)
mise run release-deploy  # semantic-release + deploy tagged version
```

Backend image: `cgr.dev/chainguard/static` (no shell — healthcheck uses `/financensor -health`).

## Key Quirks

- **SQLite CGO_ENABLED=0**: uses `modernc.org/sqlite` (pure Go), no cgo needed
- **Chainguard static image**: no shell, no package manager. `init()` in main.go creates dirs at startup
- **TanStack Router codegen**: `src/routeTree.gen.ts` is auto-generated by the Vite plugin on build/dev. Don't edit manually
- **Tailwind v4**: CSS-first config in `src/index.css` via `@theme`, no `tailwind.config.js`
- **Frontend API_BASE**: switches between `/api/v1` (dev, Vite proxy) and full URL (prod) via `import.meta.env.PROD`
- **DB migrations**: inline in `backend/internal/db/migrate.go` (no migration tool, just `CREATE IF NOT EXISTS`)
- **SQLite viewer**: Datasette on `db.financensor.stammkneipe.dev`, protected via Traefik Basic Auth using `DATASETTE_BASIC_AUTH` from `.env.production`

## Environment Variables (backend)

Required for OAuth: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
Optional: `DB_PATH` (default: `financensor.db`), `JWT_SECRET`, `FRONTEND_URL`, `GOOGLE_REDIRECT_URL`

Local dev: create `backend/.env` (loaded by godotenv). See `backend/.env.example`.

## Project Conventions

- German UI text
- Amounts stored as `int64` cents (`amount_cents`)
- UUIDs as TEXT primary keys (generated via `github.com/google/uuid`)
- REST API prefix: `/api/v1`
